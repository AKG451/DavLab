# 📊 DavLab - Data Visualization Laboratory

This repository contains the weekly lab exercises, code submissions, and datasets for the **CSS 1022 Data Visualization** course at Manipal Institute of Technology (MIT).

## 📂 Repository Structure
The repository is organized by weeks, aligned with the course syllabus:

| Folder | Topic | Key Concepts |
| :--- | :--- | :--- |
| **week1** | Python Basics | Functions, Loops, Calculator logic, Prime checks |
| **week2** | Data Structures | Lists, Tuples, Dictionaries, Sets |
| **week3** | NumPy & Linear Algebra | Arrays, Matrix operations, Vectorized computation |
| **week4** | Pandas Introduction | DataFrames, Series, Loading CSVs, Data wrangling |
| **week5** | Data Cleaning | Handling missing values, Noisy data treatment |
| **week6** | Visualization I | Matplotlib basics, Line/Bar charts |
| **week7** | Visualization II | Seaborn, Heatmaps, Box plots |
| **week8-12** | Advanced & Case Studies | Grouping, String manipulation, Final Reporting |

## 🛠️ Tech Stack & Tools
The following tools and libraries are used throughout these experiments :
* **Language:** Python 3.x
* **Environment:** Anaconda Distribution / Jupyter Notebook
* **Core Libraries:**
    * `NumPy`: Numerical computations
    * `Pandas`: Data manipulation and analysis
    * `Matplotlib`: Basic plotting
    * `Seaborn`: Advanced statistical visualization
